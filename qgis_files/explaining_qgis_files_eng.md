# Description of the files inside the QGIS folder

## Bed materials
The folder [bed_materials](https://github.com/valentinevln27/stage_m2_croisic/tree/main/qgis_files/bed_materials) contains the files of the sutudied domain's bed materials. This layer gives, for each place, the bed materials' class (rock, gravel, sand and mud) as well as the corresponding value of roughness length z₀, depending on diverse possible combination.

## Outlines
The folder [outline_croisic](https://github.com/valentinevln27/stage_m2_croisic/tree/main/qgis_files/outline_croisic) is composed of the line delimiting the domain without the storm surge barrier at Le Croisic. 
The folder [outline_gate](https://github.com/valentinevln27/stage_m2_croisic/tree/main/qgis_files/outline_gate) gives, quant à lui, the outline of the domain with this storm surge gate.
Finally, the folder outline_island regroup all islands outline included in the domain.
