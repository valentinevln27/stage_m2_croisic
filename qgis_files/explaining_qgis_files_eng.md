# Description of the files inside the QGIS folder

## Bed materials
The folder [bed_materials](https://github.com/valentinevln27/stage_m2_croisic/tree/main/qgis_files/bed_materials) contains the final files for the studied domain's bed materials. This layer provides, for each zone, the bed material's class (rock, gravel and pebbles, sand and mud) as well as the corresponding roughness length value (z₀), depending on diverse possible combinations.

## Outlines
The folder [outline_croisic](https://github.com/valentinevln27/stage_m2_croisic/tree/main/qgis_files/outline_croisic) is composed of the final line delimiting the domain without the storm surge barrier at the Pen Bron channel. 
Meanwhile, the folder [outline_gate](https://github.com/valentinevln27/stage_m2_croisic/tree/main/qgis_files/outline_gate) gives the outline of the domain with this storm surge gate.
Finally, the folder outline_island regroup all islands' outlines included in the domain.
